One controlled step to create the organization, its first administrator, and the default security policy. The installer can hand off known values so the browser only asks for what is still missing.

Secure the administrator

Set the credential used for the first console sign-in. This is the only time the password is entered in the setup flow.

Never write this value to .env or installer logs. Store only a one-way hash.
MFA recommendation
Require an authenticator challenge for this admin after the first successful sign-in. Recovery codes should be shown once and acknowledged before leaving setup.
Production safety: the bootstrap endpoint must be disabled as soon as the first organization exists, and the action must be rate-limited and audit logged.
