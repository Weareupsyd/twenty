Chunguza Screening Platform

Chunguza (Swahili: to investigate, examine, inspect, scrutinize) is a self-hosted investigative AML & sanctions screening console powered by FastAPI, Yente, and OpenSanctions with multi-role RBAC, African geometric branding, rich analyst triage cockpit, and printable regulatory reports.

Air-gapped VPC · Zero Outbound Egress OpenSanctions · 1.48M+ Entities Multi-Role RBAC: Super User / Reviewer / Analyst / Auditor Somali & Arabic Transliteration

Review notes before implementation
01 · bootstrap contract

Have install.sh collect organization + admin identity, pass them through a namespaced handoff, and keep passwords out of the environment file and logs.

02 · one auth story

The current code has developer OTP, reviewer OTP, and password-based admin routes. Pick the console entry point explicitly so the UI, seeded user, and route all agree.

03 · real tenant context

Seed an organization id and carry it through admin claims, policies, thresholds, API keys, audit events, and the header switcher. Avoid using a user id as a temporary organization id.

04 · operational states

Design loading, empty, error, expired-session, locked-account, MFA recovery, permission denied, and mobile states alongside the happy path.
